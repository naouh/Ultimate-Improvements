# DartCraft Wiki — Minecraft 1.4.7 (Beta 0.1.10)

> "Bringing a new level of convenience to Minecraft." — bluedart

DartCraft is a **Minecraft 1.4.7** mod by **bluedart** that adds Force-themed tools, blocks, and an upgrade system. This wiki documents the **Beta 0.1.10** build (the final 1.4.7 release). Tools and gear are infused with **Force Upgrades** at a **Force Infuser** using **Liquid Force** and Minecraft Joules (BuildCraft MJ). Progression is gated by a **Force Tome** that levels up as you infuse.

This wiki was generated by reading the decompiled source of `DartCraft.jar` — it documents what the mod actually does, not what older changelogs claim.

## Optional integrations

DartCraft auto-detects these mods at load and adds recipes / hooks when present:

- **BuildCraft** — Force Engine accepts MJ, BC gates get DartCraft triggers (Has Tome / Can Upgrade), Force Gear becomes the BC Gear, Force Wrench-style upgrades.
- **IC2** — Power Drill and Power Saw items get registered; macerator recipes (lead ore → lead dust, tungsten ore → diamonds); silver dust smelting fix; UU-Matter recipes; battery becomes a Charge upgrade material.
- **Forestry** — Carpenter recipes for Force Ingots (from gem + ingotBronze/RefinedIron/Silver/Xychoridite), Squeezer recipes (Force Gem → 1.5 B Liquid Force + Force Shard; Force Logs → Liquid Force), force-tree crop provider, force can/capsule containers, hunter backpack accepts tears/claws/lambchops, optional crated Nikolite & Brass.
- **Thermal Expansion** — Sawmill: Force Wood → 6× Force Planks + sawdust.
- **Railcraft** — Steel tools/armor become Force-transmutable.
- **Thaumcraft** — Object tags registered for every DartCraft item/block so they can be researched.
- **NEI** — Custom NEI handler so Infuser recipes show up.
- **GregTech** — Late-init "molestation consolement" rebuild of IC2 hooks.

## Worldgen

- **Power Ore** spawns in the Overworld up to Y=48: 8 veins/chunk, 4 ore/vein (defaults). Also spawns in the Nether at 1.5× rate (configurable).
- **Force Trees** generate naturally if the world generator places saplings (cyan-leaved trees that drop Force Wood).
- **Cold Cow**, **Cold Chicken**, **Ender Tot** entities have spawn entries (Ender Tot spawns in all biomes except Hell).

## Configuration highlights (`config/dartcraft.cfg`)

| Category | Key options |
|---|---|
| `worldGen` | enable ore in overworld/nether, vein size, Y-cap, regen |
| `upgrades` | Ender Bow, Nether Star Recipe, Holding |
| `plugins` | toggle each integration |
| `packs` | initial Force Pack size (8–40, multiples of 8), blacklist Forestry packs |
| `holding` | allow bottling Creepers (default off), Ghasts (on), passive-only mode |
| `fuels` | enable Lava / Oil / Fuel / BioFuel / Milk in Force Engine |
| `misc` | Debug Punch toggle + damage (0–20), flight particle level (0–3) |
