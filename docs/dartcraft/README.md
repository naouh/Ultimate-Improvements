# DartCraft Wiki — Minecraft 1.4.7 (Beta 0.1.10)

![DartCraft logo](images/logo.png)

> "Bringing a new level of convenience to Minecraft." — bluedart

DartCraft is a **Minecraft 1.4.7** mod by **bluedart** that adds Force-themed tools, blocks, and an upgrade system. This wiki documents the **Beta 0.1.10** build (the final 1.4.7 release), cross-referenced with the **0.1.11** wiki for the upgrade tables and integrations (1.4.7 and 1.5.1 share the same upgrade mechanics with a handful of tier shifts; see the per-page notes).

**Sources** : decompiled `DartCraft.jar` (the 1.4.7 binary) ; bluedart's [0.1.11 forum thread](https://web.archive.org/web/20130509170724/http://www.minecraftforum.net:80/topic/1686840-151-dartcraft-beta-0111/) (archived) for upgrade tables and behaviour ; the [UpsilonFixes](../../UpsilonFixes) coremod for the known bug list.

## Optional integrations (summary)

DartCraft auto-detects these mods at load. Full per-integration detail in [integrations.md](integrations.md).

- **BuildCraft** — Force Engine outputs MJ, BC Triggers `Has Tome` / `Can Upgrade`, Force Gear as BC Gear, Force Bricks/Wood as facade materials, Force Gear substitutes for Gold Gear in Quarry/Filler/Diamond Gear recipes.
- **IC2** — Power Drill and Power Saw items registered ; macerator (lead → dust, tungsten → 2× diamond) ; silver dust smelt fix ; Energy Crystal recipe using `gemRuby` ; UU-Matter → Force Gems ; battery becomes a Charge upgrade material.
- **Forestry** — Carpenter recipes for Force Ingots and Inert Cores ; Squeezer (Force Gem → 1.5 buckets Liquid Force + Force Shard ; Force Logs → Liquid Force) ; Force-tree crop provider ; Force can / wax capsule / refractory capsule for Liquid Force and milk ; hunter backpack accepts Tears / Claws / Lambchops ; optional crated Nikolite, Brass, UU-Matter.
- **Thermal Expansion** — Sawmill: 1 Force Log → 6 Force Planks + sawdust.
- **Railcraft** — Steel tools/armor are Force-transmutable.
- **Thaumcraft** — Aspects registered for every DartCraft item/block.
- **NEI** — Custom NEI handler for Workbench / Infuser recipes.
- **GregTech** — DartCraft tries to **revert GregTech's harder IC2 recipes** at post-init (the "Applying postliminary IC2 molestation consolement" log line). This is **misguided** — GregTech has its own config to disable those recipes selectively. [UpsilonFixes](upsilonfixes.md) patches this out via `fixDartCraftForceDisablingGregTechTweaks`.

## Worldgen

- **Power Ore** spawns in the Overworld up to **Y=48**: **8 veins/chunk**, **4 ore/vein** (config defaults). Also spawns in the Nether at **1.5×** the Overworld rate (configurable).
- **Force Trees** are not generated by world-gen — saplings can be obtained as drops from leaves or via Forestry sapling roulette.
- **Cold Cow**, **Cold Chicken**, **Ender Tot** entities are registered. **Ender Tot** spawns in every biome except Hell (`weight=3, min=1, max=2`). [UpsilonFixes](upsilonfixes.md) additionally excludes Mushroom Island + Mushroom Island Shore via `fixDartCraftMobSpawnRegistration`.

## Configuration highlights (`config/dartcraft.cfg`)

| Category | Key options |
|---|---|
| `worldGen` | Generate Power Ore (overworld / Nether), Ore Per Vein (4), Veins Per Chunk (8), Max Spawn Height (48), Nether frequency (1.5×, clamped 0.25–3.0), Auto-regen ore |
| `upgrades` | Ender Bow, Nether Star Recipe, Holding (Bottling of Entities) |
| `plugins` | Forestry, IC2, Thermal Expansion, Thaumcraft, Railcraft, Crated Nikolite/Brass |
| `packs` | Initial pack size (8–40, multiples of 8), blacklist Forestry packs |
| `holding` | Allow bottling Creepers (off), Ghasts (on), Passive-only mode |
| `fuels` | Force Engine: enable Lava / Oil / Fuel / BioFuel / Milk |
| `misc` | Debug Punch toggle + damage (0–20, default 8), Flight Particles (0=none, 1=others, 2=others+self, 3=+creative) |

## Known bugs / gotchas — see [UpsilonFixes patches](upsilonfixes.md)

Three issues in the 1.4.7 build that the UpsilonFixes coremod patches:

1. **Force Engine throttled below capacity** — internal `transferEnergy` is hardcoded at 250 MJ/cycle (10 MJ/t) but the engine can actually generate up to 400 MJ/cycle (16 MJ/t). Power above 10 MJ/t is silently wasted. Fix flag: `fixDartCraftForceEngineLimit`.
2. **Force Infuser "Go" button uses wrong dimension** — the packet handler calls `worldServerForDimension(0)` (hardcoded Overworld) instead of the player's actual world, so the Infuser can be unusable from other dimensions. Fix flag: `fixDartCraftForceInfuserDimension`.
3. **GregTech tweak-reversal at post-init** — see Integrations above. Fix flag: `fixDartCraftForceDisablingGregTechTweaks`.

Plus the Mushroom Island spawn issue. All four are off by default in UpsilonFixes config — enable them per-pack.
